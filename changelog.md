## 1.1.0

#### Added

- List settings from mods built with YACL, Cloth Config, MidnightLib, or Forge Config API Port now open in Mod Hub's own page, with a row per item and buttons to add, remove, and reorder. A list Mod Hub can't draw still opens the mod's own screen.

#### Changed

- A list's name sits on its toolbar line next to its buttons. Remove grays out at the list's minimum length, the same as Add does at its maximum.
- The Options look setting is now called Default look, and its off state is the Panel look. The switch itself is now a toggle naming the look on its face, not a checkbox.
- Requires MenuKit 7.4.0 or newer.
