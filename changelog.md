## 1.0.0

First release.

- A mod list, opened from a new button in the pause menu, with search and each mod's version, description and links.
- Open any mod's settings from its page. This works for mods built on Mod Hub and for mods that register a config screen for Mod Menu, with or without Mod Menu installed.
- Shortcut buttons for the mods you pick, at the top of the pause menu and of the inventory and other screens with slots, and a key for each mod.
- With Keybindery 1.2.2 or newer, a button that opens Key Binds showing one mod's keys.
- For mod authors: declare on/off, number and choice settings in code, and Mod Hub saves them and draws the screen. Related mods can be grouped into a suite.
