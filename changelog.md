## 1.0.0

First release.

### Added

- A mod list, opened from a new button in the pause menu and on the title screen, with search and each mod's version, description, and links.
- A button on each mod's page that opens its settings. This works for mods built on Mod Hub and for mods that register a settings screen for Mod Menu, with or without Mod Menu installed.
- Settings from mods built with YACL, Cloth Config, MidnightLib, or Forge Config API Port open in Mod Hub's own page, including color and item settings. A mod with a setting Mod Hub can't draw yet opens its own screen, and a setting in Mod Hub's settings turns this off.
- Undo and Redo on settings pages.
- Shortcut buttons for chosen mods at the top of the pause menu and of the inventory and other screens with slots, and a key for each mod.
- With Keybindery 1.2.2 or newer, a button that opens Key Binds showing one mod's keys.
- For mod developers, on/off, number, and choice settings declared in code, which Mod Hub saves and draws a screen for. Related mods can be grouped into a suite.
